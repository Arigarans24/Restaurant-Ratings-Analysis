Restaurant Ratings Analysis

Cognifyz Technologies Data Analytics Internship

Level 2 - Task 1

Project Overview

This project focuses on analyzing restaurant ratings and customer voting patterns using Python. The analysis helps understand the distribution of restaurant ratings, identify the most common rating range, and determine the average number of votes received by restaurants.

Dataset

The dataset contains information about restaurants, including:

- Restaurant Name
- Aggregate Rating
- Votes
- Other restaurant-related attributes

Technologies Used

- Python
- Pandas
- Matplotlib

Objectives

- Analyze the distribution of aggregate ratings.
- Identify the most common rating range.
- Calculate the average number of votes received by restaurants.
- Visualize rating distribution using a histogram.

Steps Performed

1. Loaded the dataset using Pandas.
2. Explored and analyzed the Aggregate Rating column.
3. Grouped ratings into different rating ranges.
4. Counted the number of restaurants in each range.
5. Determined the most common rating range.
6. Calculated the average number of votes.
7. Created a histogram to visualize rating distribution.

Results

- Most Common Rating Range: 3 - 4
- Average Number of Votes Received: 156.91

Output Visualization

A histogram was generated to display the distribution of aggregate ratings among restaurants.
